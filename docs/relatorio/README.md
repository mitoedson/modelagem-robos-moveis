# Relatório final

[`Relatorio_Final_ABNT.pdf`](Relatorio_Final_ABNT.pdf): relatório técnico no padrão ABNT (NBR 14724, 6024, 6023, 10520) com introdução, metodologia, resultados e discussão, conclusão e referências, sobre os três cenários (círculo, reta e ponto de chegada).

Os valores quantitativos do relatório vêm da réplica em Python ([`python/`](../../python)); os gráficos do Simulink foram usados para verificação qualitativa. Este repositório estende o relatório com o estudo teórico ([`docs/`](..)) e o código.
